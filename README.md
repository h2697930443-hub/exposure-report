# 企业公网资产暴露面测绘

用公开信息（证书透明度日志 + 公开 DNS）摸清企业在公网上的全部资产，按风险分级，输出可直接交给运维的报告。

**在线说明页**：https://h2697930443-hub.github.io/exposure-report/

## 做什么

- 被动子域枚举：不接触目标系统，只读公开证书日志和 DNS
- 存活探测：每台主机只访问一次首页，确认服务状态与技术特征
- 资产分类：按主机名语义归类为内部系统 / 数据平台 / 管理后台 / 测试环境 / 接口服务
- 风险分级：只有「当前可解析 + 内部系统」才判高危，未解析的归为历史记录
- 报告输出：PDF（结论 + 清单 + 修复优先级）+ Excel 台账

## 边界

不做渗透测试、不做漏洞利用、不做数据读取。全程只读公开信息，
每个地址只发起一次 HTTP 请求。

## 交付形态

| 文件 | 内容 |
|---|---|
| report.pdf | 4-6 页，结论、风险清单、处置建议 |
| assets.xlsx | 逐主机台账：地址、类型、状态、分级、建议 |

Excel 台账按等保测评底稿字段设计，可直接作为测评附件。

## 为什么有用

内部台账只知道「应该存在」的系统；公开信息能看到「实际暴露」的系统。
这两份清单的差集，就是暴露面。
