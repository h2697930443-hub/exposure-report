Every row carries source_url — click through and verify. Nothing here is generated.

Four decisions that matter

  • Fail loudly, never return an empty table. If the list endpoint comes back empty, the script exits with an error. Silent empty output is the worst failure mode: the buyer thinks "no leads today" when the parser actually broke.
  • Idempotent. unique_key = md5(source + original_id). Running it every hour will not duplicate rows.
  • Intent scoring is explainable. Each row carries a signals field — hiring | budget | tech need — so the buyer can audit why a lead is grade A. No black box.
  • Config-driven. A source is two URLs: a list endpoint and a detail endpoint. Swapping platforms means adding one dict entry, not editing code.
What this is not: the demo runs against a public API (no login, reproducible) rather than a vertical-specific site. A real engagement plugs in the client's own account or a public source they can legally collect. I say that up front rather than showing a scraped dashboard I cannot prove.
