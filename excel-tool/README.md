# Excel 小工具

四个功能，解决最费时间的活。
**不用装 Excel 插件，不用写公式，全程本地运行。**

## 四个功能

### 合并
把一个文件夹里所有 Excel 合成一张表，自动加「来源文件」列。
以后数据对不上，能立刻知道是哪个文件的问题。

### 去重
按指定列（订单号、身份证号、ID）去重，保留第一条。

### 拆分
按某列拆成多个文件。按「部门」拆，就有销售部.xlsx、技术部.xlsx...

### 对比
两个表找出差异，输出两个 sheet：「只在A表」「只在B表」。

## 怎么用

需要 Python 3（免费，[下载地址](https://www.python.org/downloads/)）。

```bash
# 第一次运行，装依赖
pip install pandas openpyxl

# 启动
python3 gui.py
```

Windows 用户：安装 Python 时记得勾选 **Add Python to PATH**。

## 三个注意事项

**一、表头在第一行**
工具默认第一行是表头。表前面有标题行的话，先删掉。

**二、不要有合并单元格**
会导致读取错乱。用之前先取消所有合并。

**三、对比前检查格式**
如果两边看起来一样但对比结果不对，可能是数字 vs 文本，或者有不可见空格。
检查：`=LEN(A2)-LEN(TRIM(A2))`，不为 0 就是有空格。
